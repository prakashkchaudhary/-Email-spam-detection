About SpamGuard AI

Advanced Email Spam Detection using Machine Learning & NLP

📋 Project Overview

SpamGuard AI is a comprehensive email spam detection system that leverages the power of Machine Learning and Natural Language Processing to identify and classify spam messages with high accuracy. This project demonstrates the practical application of AI/ML techniques in solving real-world cybersecurity challenges.

🛠️ Technology Stack

Backend

  • Python 3.11
  • Flask Web Framework
  • Scikit-learn
  • NLTK

Machine Learning

  • Naive Bayes
  • Logistic Regression
  • Random Forest
  • Support Vector Machine

NLP Techniques

  • Tokenization
  • Stemming
  • Stopword Removal
  • TF-IDF Vectorization

Frontend

  • HTML5
  • CSS3
  • JavaScript
  • Responsive Design

⚙️ How It Works

1

Data Collection

Training data collected from SMS Spam Collection Dataset containing thousands of labeled spam and ham messages

2

Preprocessing

Text cleaning including lowercasing, removing URLs, punctuation, special characters, and applying stemming

3

Feature Extraction

Converting text to numerical vectors using TF-IDF (Term Frequency-Inverse Document Frequency)

4

Model Training

Training multiple ML models and selecting the best performer based on accuracy, precision, and recall

5

Prediction

Real-time classification of new messages with confidence scores and detailed analysis
