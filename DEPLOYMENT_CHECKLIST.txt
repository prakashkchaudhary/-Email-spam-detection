└──────────────────────────────────────────────────────────────────────────────┘

  Option 1: VERCEL (Recommended for Serverless)
  ─────────────────────────────────────────────
    • Best for: Static sites, serverless functions
    • Free tier: 100 GB bandwidth/month
    • Deploy time: 2-3 minutes
    • URL: https://your-project.vercel.app
    
    Steps:
    1. Run: deploy.bat (Windows) or ./deploy.sh (Unix)
    2. Push to GitHub
    3. Go to https://vercel.com
    4. Sign in with GitHub
    5. Click "Add New Project"
    6. Select your repository
    7. Click "Deploy"

  Option 2: RENDER (Recommended for Full-Stack)
  ──────────────────────────────────────────────
    • Best for: Full-stack apps, persistent processes
    • Free tier: 750 hours/month
    • Deploy time: 5-10 minutes
    • URL: https://your-app.onrender.com
    
    Steps:
    1. Run: deploy.bat (Windows) or ./deploy.sh (Unix)
    2. Push to GitHub
    3. Go to https://render.com
    4. Sign in with GitHub
    5. Click "New +" → "Web Service"
    6. Select your repository
    7. Configure build and start commands
    8. Click "Create Web Service"
